# 🛠️ Scripts - Endurance Lab AI

Esta carpeta contiene todos los scripts de utilidad y automatización.

## 📋 Scripts Disponibles

### 🚀 Inicio y Configuración
- `start.py` - Inicio rápido de la aplicación
- `setup_project.py` - Configuración inicial del proyecto
- `restart_app.py` - Reinicio con interfaz mejorada

### 🔧 Utilidades
- `create_vectorstore.py` - Creación del vectorstore
- `test_basic.py` - Tests básicos del sistema
- `cleanup.py` - Limpieza de archivos temporales

### 📊 Evaluación
- `run_evaluation.py` - Ejecutar evaluaciones automáticas
- `export_results.py` - Exportar resultados

## 🎯 Uso

Ejecuta cualquier script desde la raíz del proyecto:

```bash
python scripts/start.py
python scripts/setup_project.py
```
